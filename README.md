# برنامج حسابات العباري لصيد الأسماك

## الموجود في الإصدار الأول
- لوحة تحكم بتصميم بحري كحلي وذهبي.
- إدارة عدة عباري مع فصل بيانات كل عبري.
- عنوان «تجهيز العبري للإبحار» وتحته: المواد الغذائية، مستلزمات وتجهيزات العبري، المشتقات النفطية، الثلج والماء.
- تسجيل المصروفات وحساب الكمية × سعر الوحدة.
- سجل الصيادين مع العنوان والجوال والرصيد الافتتاحي.
- تسجيل الدين والسداد وحساب الرصيد الحالي.
- بيانات رخصة دخول مياه الصومال.
- إجماليات وتصدير/مشاركة PDF.
- حفظ محلي تلقائي على الجهاز.

## مهم بخصوص النسخ الاحتياطي
حقل البريد في هذا الإصدار يحفظ عنوان البريد محليًا فقط. لا توجد مزامنة سحابية بعد. لا تعتمد عليه وحده لحماية البيانات من فقدان الهاتف. النسخ السحابي الآمن يحتاج إعداد Firebase/مصادقة وقواعد صلاحيات واختباره في مرحلة لاحقة.

## البناء من GitHub عبر الهاتف
1. أنشئ مستودعًا جديدًا في GitHub وارفع ملفات هذا المشروع مع المجلدات.
2. افتح تبويب Actions وشغّل `Build Fishing Boat Accounts APK`.
3. عند النجاح افتح نتيجة التشغيل ونزّل Artifact باسم `fishing-boat-accounts-apk`.
4. فك الضغط عن Artifact لتحصل على ملف APK.

إذا استخدمت مستودعًا موجودًا، لا تستبدل ملفات تطبيق آخر قبل أخذ نسخة احتياطية.
